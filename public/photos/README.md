# Zagros — Photography brief

All hero / report imagery in v1 uses placeholder JPEGs marked
"illustrative — pending client photography." When the client supplies
real photos, drop them in this directory with the same filenames.

## Treatment (spec §2.5)

- Slight desaturation, warm-bias grading
- Real farms, real workers, no stock-photo poses
- 16-stop grain matching the paper-grain body texture
- Target dimensions: 1600px on the long edge minimum, JPEG quality 82

## What's here now

The current files are sienna-toned solid-color JPEGs with "ILLUSTRATIVE"
written across them. They are placeholders — they will be replaced by
real client photography before the demo is shown.
